# Beginner Lesson Progression

Status: PROPOSAL
Scope: beginner lesson progression
Normative authority: none; requires explicit adoption

This document gives the first 15 Spanish A0 lesson plans at the scenario level.
It does not design individual exercises and does not create content assets.

Each lesson has one primary objective and one measurable communicative gain.

New-material counts treat fixed expressions as phrase chunks. A phrase chunk may
contain more than one written word, but it is counted as one new communicative
unit only when it is taught and assessed as a fixed beginner expression.

The full alphabet is not taught in these lessons. Every lesson that asks the
learner to read, recognize or type a new written form must provide local
WritingUnit support for the exact letters, accent marks, punctuation marks or
letter combinations required by that form before active use.

## Lesson 1: First Spanish Hello

Objective:
Learner reads, understands, and types `Hola.`

Communicative outcome:
Learner can produce a first Spanish hello.

New knowledge introduced:

- Vocabulary: `Hola.`
- Reading rules: silent `h` in `Hola`.
- Grammar: none.
- Communication: greeting someone.
- Pronunciation: support-language reading of `Hola`.
- Writing: local support for the written letters in `Hola`; type `Hola` from
  memory after supported reading.

Cognitive load:

- New words: 1.
- New concepts: greeting; quiet written `h`.
- New pronunciation rules: 1.
- Reading difficulty: very low; one short word.

Why appropriately sized:
The lesson gives one useful success and one reading fact. It avoids alphabet,
grammar, and phrase expansion.

Exercise progression:

```text
Purpose
-> supported encounter
-> meaning recognition
-> supported decoding
-> changed-context recognition
-> guided recall
-> independent recall
-> closure
```

Review strategy:
None. This is the first lesson.

Why here:
Textbook research supports early pronunciation support, but Tutor Language
adapts it into a communicative micro-success instead of a phonetic table.

## Lesson 2: Greeting a Person

Objective:
Learner reads and produces `Hola, Ana.` as a greeting to a named person.

Communicative outcome:
Learner can greet a person by name.

New knowledge introduced:

- Vocabulary: `Ana` as a name.
- Reading rules: simple vowel continuity in `Ana`.
- Grammar: comma/name address pattern only as use, not terminology.
- Communication: greeting an addressee.
- Pronunciation: support for `Ana`.
- Writing: local support for `Ana` and the comma as address punctuation; type
  `Hola, Ana` from situation.

Cognitive load:

- New words: 1 name.
- New concepts: greeting can include a name.
- New pronunciation rules: 0-1; no broad vowel lesson.
- Reading difficulty: low; reuses `Hola`.

Why appropriately sized:
The only new target is the name and the address function. `Hola` is reused.

Exercise progression:

```text
Review recall of Hola
-> supported encounter with name
-> meaning/role recognition
-> supported reading of full greeting
-> changed addressee context
-> non-leaking guided recall
-> independent production
-> micro review
```

Review strategy:
Reviews `Hola` through recall before adding the name.

Why here:
The learner first needs a stable greeting word before using it with a person.

## Lesson 3: Greeting Question

Objective:
Learner understands and recognizes `¿Qué tal?`

Communicative outcome:
Learner can recognize that someone is asking how they are.

New knowledge introduced:

- Vocabulary: `¿Qué tal?`
- Reading rules: whole-phrase support for `¿Qué tal?`; inverted question marks
  as visible question support; `Qué` is read as part of the fixed phrase, with
  `qu` and accented `é` not generalized yet.
- Grammar: question function only.
- Communication: greeting question.
- Pronunciation: support for the whole phrase.
- Writing: none required.

Cognitive load:

- New words/phrase chunks: 1 phrase.
- New concepts: question asks for a response; inverted question marks mark a
  question.
- New pronunciation rules: 0 broad rules; phrase support only.
- Reading difficulty: moderate because punctuation and accent appear, but the
  phrase is taught as one supported chunk.

Why appropriately sized:
The lesson is comprehension-only. It does not also require answering.

Exercise progression:

```text
Review greeting
-> supported encounter with question
-> meaning recognition
-> supported reading
-> changed-context recognition
-> brief interference
-> recognition without full support
-> closure
```

Review strategy:
Reviews `Hola` and `Hola, Ana` as known greeting contexts.

Why here:
Questions should be understood before the learner is asked to answer them.

## Lesson 4: Simple Answer

Objective:
Learner answers `¿Qué tal?` with `Bien.`

Communicative outcome:
Learner can give a basic answer to a greeting question.

New knowledge introduced:

- Vocabulary: `Bien.`
- Reading rules: supported reading of `Bien`; no full `ie` rule yet.
- Grammar: answer relation to question.
- Communication: responding politely to `¿Qué tal?`
- Pronunciation: support for `Bien`.
- Writing: local support for the written form `Bien`; type after supported
  reading.

Cognitive load:

- New words: 1.
- New concepts: answer to known question.
- New pronunciation rules: 0 broad rules; word-level support.
- Reading difficulty: low-moderate.

Why appropriately sized:
The question is already known, so the lesson can focus on the answer.

Exercise progression:

```text
Review question recognition
-> supported encounter with answer
-> meaning recognition
-> supported reading
-> guided recall
-> independent recall after known question
-> closure
```

Review strategy:
Reviews `¿Qué tal?` as the cue for the answer.

Why here:
Answer production would overload Lesson 3; separating it keeps one primary
objective.

## Lesson 5: First Mini Exchange

Objective:
Learner completes the exchange `Hola. ¿Qué tal? Bien.` in order.

Communicative outcome:
Learner can handle a tiny greeting exchange.

New knowledge introduced:

- Vocabulary: none.
- Reading rules: none.
- Grammar: turn order in a greeting exchange.
- Communication: greeting, question, answer sequence.
- Pronunciation: review only.
- Writing: produce known lines in order.

Cognitive load:

- New words: 0.
- New concepts: exchange order.
- New pronunciation rules: 0.
- Reading difficulty: controlled; all forms known.

Why appropriately sized:
This is integration, not expansion. It prevents early phrasebook fragments.

Exercise progression:

```text
Recognition review
-> order recognition
-> guided reconstruction
-> independent production of known parts
-> controlled use
-> closure
```

Review strategy:
Reviews Lessons 1-4 with changed response type and turn order.

Why here:
After four micro-skills, the learner needs a meaningful integration checkpoint.

## Lesson 6: Goodbye

Objective:
Learner reads, understands, and types `Adiós.`

Communicative outcome:
Learner can say goodbye.

New knowledge introduced:

- Vocabulary: `Adiós.`
- Reading rules: written accent marks the strong syllable in this word.
- Grammar: none.
- Communication: farewell.
- Pronunciation: support for `Adiós`.
- Writing: local support for the accented `ó`; early typed production may treat
  missing accent as accepted-with-feedback, but the learner still sees the
  accented target form before recall.

Cognitive load:

- New words: 1.
- New concepts: farewell; accent as reading support.
- New pronunciation rules: 1 local fact.
- Reading difficulty: moderate due to accent.

Why appropriately sized:
The lesson adds one social function and one visible reading fact.

Exercise progression:

```text
Review greeting exchange
-> supported encounter
-> meaning recognition
-> supported decoding
-> guided recall
-> independent recall
-> closure
```

Review strategy:
Reviews `Hola` contrastively as greeting, not farewell.

Why here:
Goodbye is the natural counterpart to greeting, but it should not compete with
the first hello lesson.

## Lesson 7: Greeting or Farewell

Objective:
Learner recognizes whether `Hola.` or `Adiós.` fits a greeting or farewell
context.

Communicative outcome:
Learner can choose the appropriate known greeting or farewell in context.

New knowledge introduced:

- Vocabulary: none.
- Reading rules: review silent `h` and accent.
- Grammar: none.
- Communication: arrival vs departure.
- Pronunciation: review only.
- Writing: none required; this lesson assesses contextual recognition, not new
  production.

Cognitive load:

- New words: 0.
- New concepts: communicative contrast.
- New pronunciation rules: 0.
- Reading difficulty: low; known words.

Why appropriately sized:
The lesson changes context and decision demand without adding language.

Exercise progression:

```text
Changed-context recognition
-> contrast discrimination
-> reduced-support contextual recognition
-> independent contextual choice from known options
-> micro review
```

Review strategy:
Reviews `Hola` and `Adiós` with plausible distractors.

Why here:
The learner needs to avoid using memorized words without communicative control.

## Lesson 9: You're Welcome

Objective:
Learner understands and produces `De nada.` as a response to `Gracias.`

Communicative outcome:
Learner can respond to thanks.

New knowledge introduced:

- Vocabulary: `De nada.` as one fixed response phrase.
- Reading rules: simple supported syllable reading.
- Grammar: response pairing only.
- Communication: thanks-response exchange.
- Pronunciation: support for `De nada`.
- Writing: local support for the written words `De nada`; type after supported
  reading.

Cognitive load:

- New phrase chunks: 1 fixed response phrase containing two written words.
- New concepts: paired response.
- New pronunciation rules: 0 broad rules.
- Reading difficulty: low-moderate.

Why appropriately sized:
The new phrase depends on `Gracias`, which is now known.

Exercise progression:

```text
Review Gracias
-> supported encounter with response
-> meaning recognition
-> pair recognition
-> guided recall
-> independent response
-> closure
```

Review strategy:
Reviews `Gracias` as the trigger for the response.

Why here:
Paired exchanges should be built after each side is individually learnable.

## Lesson 10: Please

Objective:
Learner reads, understands, and types `Por favor.`

Communicative outcome:
Learner can use the Spanish word for please as a polite support phrase.

New knowledge introduced:

- Vocabulary: `Por favor.` as one fixed courtesy phrase.
- Reading rules: whole-phrase pronunciation support; no broad `v` or stress
  rule yet.
- Grammar: politeness function only.
- Communication: adding please to a request frame.
- Pronunciation: support for `Por favor`.
- Writing: local support for the written words `Por favor`; type after
  supported reading.

Cognitive load:

- New phrase chunks: 1 fixed courtesy phrase containing two written words.
- New concepts: please makes a request polite.
- New pronunciation rules: 0 broad rules; phrase support only.
- Reading difficulty: moderate because it is a two-word phrase.

Why appropriately sized:
The lesson introduces only one courtesy phrase. Review remains limited to
`Gracias` and `De nada` so the new phrase does not compete with the full
first-contact set.

Exercise progression:

```text
Review Gracias/De nada pair
-> supported encounter with Por favor
-> meaning recognition
-> supported reading
-> guided recall
-> independent recall
-> closure
```

Review strategy:
Reviews `Gracias` and `De nada` as known courtesy language before adding a new
politeness phrase.

Why here:
`Por favor` must be introduced before `Repite, por favor`; placing it here
keeps classroom-survival Lesson 12 from using unknown language.

Learner understands and recognizes `No entiendo.`

Communicative outcome:
Learner can recognize how to say they do not understand.

New knowledge introduced:

- Vocabulary: `No entiendo.` as one fixed survival phrase.
- Reading rules: word-level pronunciation support only.
- Grammar: fixed phrase; no verb explanation.
- Communication: classroom survival.
- Pronunciation: support for `No entiendo`.
- Writing: none required yet.

Cognitive load:

- New phrase chunks: 1 fixed survival phrase containing two written words.
- New concepts: asking for help through a survival phrase.
- New pronunciation rules: 0 broad rules.
- Reading difficulty: moderate; two-word phrase.

Why appropriately sized:
The phrase is useful but longer, so the first lesson is comprehension-focused.

Exercise progression:

```text
Review known social phrases
-> supported encounter
-> meaning recognition
-> supported reading
-> changed-context recognition
-> closure
```

Review strategy:
Contrasts survival phrase with known social phrases.

Why here:
Classroom survival becomes useful once the learner has enough known Spanish to
experience confusion meaningfully.

## Lesson 12: Please Repeat

Objective:
Learner produces `Repite, por favor.`

Communicative outcome:
Learner can ask someone to repeat.

New knowledge introduced:

- Vocabulary: `Repite`; reuses `por favor`.
- Reading rules: word-level pronunciation support for `Repite`.
- Grammar: request as fixed phrase.
- Communication: asking for repetition.
- Pronunciation: support for `Repite`.
- Writing: local support for `Repite`; type the full request from context after
  `por favor` has already been introduced.

Cognitive load:

- New words: 1 new word, `Repite`; `por favor` is already known from Lesson 10.
- New concepts: request for help.
- New pronunciation rules: 0 broad rules.
- Reading difficulty: moderate because full phrase combines known and new.

Why appropriately sized:
`Por favor` should be available as known politeness support; only `Repite` is
new.

Exercise progression:

```text
Review No entiendo
-> supported encounter with request
-> meaning recognition
-> supported reading
-> guided phrase completion
-> independent contextual production
-> closure
```

Review strategy:
Reviews `No entiendo` as the situation that motivates `Repite, por favor`.

Why here:
The learner first recognizes a problem, then learns a repair action.

## Lesson 13: My Name Is

Objective:
Learner produces `Me llamo ...` with a supported name slot.

Communicative outcome:
Learner can introduce themselves by name.

New knowledge introduced:

- Vocabulary: `Me llamo`.
- Reading rules: `ll` in `llamo`.
- Grammar: name slot after fixed phrase.
- Communication: self-introduction.
- Pronunciation: support for `Me llamo`.
- Writing: local support for the written phrase `Me llamo`; type it and choose
  a supported name slot from a controlled known-name set. Free typing of
  arbitrary personal names is deferred.

Cognitive load:

- New phrase chunks: 1 fixed phrase plus a controlled supported name slot.
- New concepts: name introduction frame.
- New pronunciation rules: 1 local `ll` fact.
- Reading difficulty: moderate.

Why appropriately sized:
The phrase is important, but the lesson avoids full verb conjugation and avoids
asking another person's name yet.

Exercise progression:

```text
Review greeting
-> supported encounter
-> phrase meaning recognition
-> supported reading with ll
-> guided production with name slot
-> independent production of fixed phrase
-> closure
```

Review strategy:
Reviews `Hola` as the opening before introducing oneself.

Why here:
Self-introduction needs enough confidence with greetings and reading support.

## Lesson 14: What Is Your Name?

Objective:
Learner understands and recognizes `¿Cómo te llamas?`

Communicative outcome:
Learner can recognize when someone asks their name.

New knowledge introduced:

- Vocabulary: `¿Cómo te llamas?` as one fixed question chunk.
- Reading rules: whole-phrase support; question marks review; accent in `Cómo`
  and `ll` are reviewed locally, not generalized into a full question or accent
  system.
- Grammar: question function only.
- Communication: asking for a name.
- Pronunciation: support for whole question.
- Writing: none required.

Cognitive load:

- New phrase chunks: 1 fixed question chunk containing three written words.
- New concepts: name question.
- New pronunciation rules: 0 new broad rules; review accent and `ll`.
- Reading difficulty: moderate-high, so production is delayed.

Why appropriately sized:
The question is longer; comprehension is enough for one lesson.

Exercise progression:

```text
Review Me llamo
-> supported encounter with question
-> meaning recognition
-> supported reading
-> changed-context recognition
-> brief interference
-> recognition without full support
-> closure
```

Review strategy:
Reviews `Me llamo` as the answer relation without requiring a full exchange yet.

Why here:
The learner should be able to say their name before needing to process the
question that asks for it.

## Lesson 15: First Contact Checkpoint

Objective:
Learner completes a short first-contact exchange using greeting, name response,
and courtesy.

Communicative outcome:
Learner can greet, answer a name question with `Me llamo ...`, and use a known
courtesy pair in a tiny first meeting.

New knowledge introduced:

- Vocabulary: none.
- Reading rules: none.
- Grammar: turn order and response matching only.
- Communication: greeting, recognized name question, name response, thanks and
  courtesy response.
- Pronunciation: review only.
- Writing: recall known forms in controlled context.

Cognitive load:

- New words: 0.
- New concepts: integrated first-contact flow using known pieces only.
- New pronunciation rules: 0.
- Reading difficulty: review of known forms.

Why appropriately sized:
The lesson is a review checkpoint. The difficulty comes from choosing and
ordering known language, not from new material.

Exercise progression:

```text
Delayed recognition review
-> function discrimination
-> turn-order reconstruction
-> guided production
-> independent controlled exchange with greeting, name response and courtesy
-> remediation if a state fails
-> closure
```

Review strategy:
Reviews exact prior capabilities: `Hola` greeting recall, `¿Cómo te llamas?`
recognition, `Me llamo ...` supported-name production, and the `Gracias`/`De
nada` courtesy pair. Classroom-survival phrases are not part of this checkpoint.

Why here:
The learner has enough small pieces to complete a narrow first-contact
interaction without introducing new language or requiring production of the
long name question.

## Quality Check

- Every lesson has one primary educational objective.
- New vocabulary per expansion lesson is limited to one word or one fixed
  phrase.
- Reading rules are introduced only for immediate use.
- Grammar remains implicit unless it directly supports the action.
- Writing begins with short known forms and expands only after recognition.
- Integration checkpoint lessons introduce no new target language.
- Integration checkpoints occur after several micro-skills, not after every
  word.

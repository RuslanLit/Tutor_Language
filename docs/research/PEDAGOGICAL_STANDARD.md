# Tutor Language Pedagogical Standard

Status: PROPOSAL
Scope: pedagogical standard
Normative authority: none; requires explicit adoption

Phase: R2E16D

Scope: mandatory reference for future Tutor Language course authoring

---

# 1. Educational Philosophy

- Lessons MUST be designed as learning processes, not collections of content
  cards.
- Lessons MUST change what the learner can do.
- Lessons MUST prioritize meaningful learner action over content inventory.
- Lessons MUST treat smartphone use as the primary learning environment.
- Lessons MUST assume that the learner has no live teacher.
- Lessons MUST replace teacher functions through authored context, support,
  feedback, correction and review.
- Lessons MUST NOT imitate textbook surface forms when the smartphone medium
  requires a different form.
- Lessons SHOULD preserve the educational function of strong textbook practice
  when changing its format.

# 2. Learning Objectives

- Every lesson MUST have one primary measurable objective.
- Every lesson objective MUST be stated as learner ability.
- Every lesson objective MUST describe observable learner action.
- A topic label MUST NOT be used as a lesson objective.
- A lesson MUST NOT include material that does not contribute to its primary
  objective or required review.
- A lesson SHOULD end with evidence that the learner can use the target material
  for a small meaningful purpose.
- A lesson MAY include secondary review only when it supports the primary
  objective without introducing a competing objective.

# 3. Lesson Design Rules

- Every lesson MUST begin from a learner-relevant need, situation or action.
- Every screen MUST have an irreplaceable pedagogical purpose.
- Every screen MUST change at least one of: learner knowledge, learner skill,
  learner context, support level, evidence state, correction state or meaningful
  reinforcement.
- A screen MUST NOT exist solely to repeat the immediately preceding screen.
- A screen MUST NOT exist solely to fill lesson time.
- A screen MUST NOT exist solely to display encouragement.
- A lesson MUST NOT be lengthened to satisfy a duration target.
- Lesson duration MUST be a consequence of required learner-state transitions.
- A lesson built around a single expression MUST be shorter than a multi-unit
  lesson unless explicit evidence shows that additional screens produce distinct
  learning states.
- A lesson MUST NOT contain more core-path screens than are necessary to reach,
  verify and consolidate the objective.
- Core-path screens and remediation screens MUST be justified separately.
- Smartphone screens MUST present one primary idea, one primary action and one
  primary decision.
- Learner-facing screens MUST NOT require long scrolling in ordinary phone use.

# 4. Exercise Design Rules

- Exercises MUST follow the learner's current state.
- Exercises MUST move from support toward independence.
- Recognition exercises MUST appear before independent recall when the target is
  new.
- Recognition exercises MUST NOT be final mastery evidence for communicative
  objectives.
- Guided recall MAY use partial support.
- Guided recall MUST NOT be counted as independent mastery.
- Independent recall MUST hide the target answer.
- Independent recall MUST hide pronunciation equivalents when they reveal the
  answer.
- Independent recall MUST hide partial spelling cues.
- Production exercises MUST be small enough for realistic success without a
  teacher.
- Copying a visible answer MUST NOT be used as evidence of learning.
- Multiple choice MAY be used for early recognition.
- Multiple choice MUST NOT be the final evidence when the lesson objective
  requires use.
- Repetition MUST change context, support, timing, task type or learner
  responsibility.
- Repetition MUST NOT be added unless it improves stability, transfer,
  confidence or evidence quality.

# 5. Language Introduction Rules

- Every new language unit MUST be introduced only when it is needed for the
  lesson objective.
- Every new language unit MUST have a clear communicative or comprehension
  purpose.
- Every new language unit MUST be reused before the lesson ends.
- Every new language unit SHOULD be reused in meaningful communication before
  the lesson ends.
- Vocabulary load MUST be justified by the communicative objective.
- Vocabulary load MUST NOT be determined by an arbitrary numerical target.
- A lesson MUST NOT artificially revolve around a single expression if the extra
  screens do not produce distinct learner-state transitions.
- A lesson MUST NOT introduce isolated vocabulary for memorization alone.
- Examples MUST use already introduced material unless the example itself is
  the point of introduction.
- Examples MUST look like plausible human communication where communication is
  the objective.
- New grammar MUST be introduced only when it is required for the learner's next
  communicative action.
- Grammar MUST NOT be explained as theory before it is needed for use.

# 6. Pronunciation Rules

- Pronunciation support MUST appear before the learner is asked to read or
  produce unfamiliar target language independently.
- Pronunciation support MUST help the learner perform the next reading or
  production action.
- Pronunciation support MUST use learner-understandable explanation before
  technical notation.
- IPA MAY appear only after an understandable learner explanation.
- IPA MUST NOT replace learner-facing pronunciation support.
- Phonetic theory MUST NOT appear unless the concept itself is the lesson
  objective.
- Full alphabet or phonetics catalogues MUST NOT appear at the beginning of a
  beginner lesson unless the lesson objective specifically requires them.
- Systematic reading rules SHOULD be introduced across the course when each rule
  unlocks immediately useful target language.
- Writing-system terminology MUST NOT appear in beginner-facing content unless
  the learner needs that term for the next action and the term is taught.

# 7. Communication Rules

- Beginner language lessons MUST give target language a communicative purpose.
- Communication MUST be represented as purposeful learner action.
- Simulated communication MUST NOT pretend that the app is a live human partner.
- Phone-native communication scenarios MAY be used when no live partner exists.
- A final communication task MUST require the learner to choose or produce
  language for a meaningful purpose.
- A lesson MUST NOT end with exposure alone when its objective is communicative.
- A lesson MUST NOT introduce a new communicative exchange in the final result
  unless that exchange has been taught.

# 8. Feedback Rules

- Feedback MUST be brief.
- Feedback MUST be specific.
- Feedback MUST be actionable.
- Feedback MUST identify what is correct, what needs repair or what support is
  needed next.
- Feedback MUST NOT introduce new target material.
- Feedback MUST NOT explain internal implementation behavior.
- Feedback MUST NOT use artificial praise as a substitute for evidence of
  progress.
- Accepted-with-correction feedback MUST distinguish communicative success from
  form repair.
- Incorrect-answer feedback MUST guide the learner toward the smallest missing
  support.

# 9. Review Rules

- Review MUST support retention, not merely repeat prior screens.
- Review MUST reuse prior material in a changed context, weaker support,
  delayed recall or meaningful application.
- Review MUST NOT introduce unrelated new material.
- Review SHOULD be planned across lessons, not only within a lesson.
- Review SHOULD distinguish immediate consolidation from delayed retrieval.
- Review MAY repeat a form without novelty only when the repetition is required
  for accessibility, correction or learner recovery.

# 10. Content Authoring Rules

- Authors MUST design the learning objective before authoring learner-facing
  content.
- Authors MUST design the learner-state sequence before choosing storage or
  exercise forms.
- Authors MUST justify every screen by its pedagogical function.
- Authors MUST remove any screen that can be deleted without weakening learning.
- Authors MUST remove learner-facing text that does not help the next learner
  action.
- Authors MUST use natural learner-language equivalents before explanations
  when teaching beginner vocabulary.
- Authors MUST NOT include teacher notes, validator language, implementation
  wording or localization instructions in learner-facing content.
- Authors MUST NOT use linguistic terminology with beginners unless the term is
  taught for immediate use.
- Authors SHOULD count interactions, decisions and instructions as cognitive
  load.
- Authors SHOULD prefer fewer stronger screens over many weak screens.
- Authors MAY document unresolved pedagogical uncertainty, but unresolved
  uncertainty MUST NOT be hidden inside learner-facing content.

# 11. Acceptance Criteria

- The lesson MUST have exactly one primary measurable objective.
- The lesson MUST achieve at least one complete learner action that matches the
  objective.
- The lesson MUST provide evidence stronger than passive exposure.
- The lesson MUST provide evidence stronger than recognition when the objective
  requires use.
- Every newly introduced language unit MUST contribute to the primary objective
  or required review.
- Every newly introduced language unit MUST be reused before lesson completion.
- Every exercise MUST have a distinct role in the progression from support to
  independence.
- Every repeated target MUST change context, support, timing, task type or
  learner responsibility.
- Every screen MUST introduce new knowledge, new skill, new context, weaker
  support, meaningful reinforcement or targeted correction.
- Every screen MUST be removable only at the cost of weaker learning,
  assessment, correction or communication.
- The lesson MUST NOT contain filler screens.
- The lesson MUST NOT contain decorative motivation screens.
- The lesson MUST NOT contain isolated vocabulary memorization.
- The lesson MUST NOT contain unnecessary phonetic theory.
- The lesson MUST NOT contain answer leakage in independent recall.
- The lesson MUST NOT use copying as mastery evidence.
- The lesson MUST NOT use multiple choice as final evidence for a communicative
  objective.
- The lesson MUST NOT revolve around a single expression for many screens unless
  each screen proves a distinct and necessary learner-state transition.
- The lesson MUST NOT exceed the number of screens required to reach, test and
  consolidate its objective.
- The lesson MUST be usable on a 6-7 inch smartphone without dense text blocks
  or long scrolling.
- Learner effort MUST produce measurable communicative, reading, recall or
  comprehension progress.
- An experienced adult learner MUST be able to explain why every screen exists.
- Every minute of core lesson time SHOULD produce measurable competence,
  clearer understanding, stronger recall or useful correction.
- Removing any core-path screen MUST weaken learner ability, evidence,
  communication or necessary support.
- The lesson MUST respect adult time by excluding interactions that consume time
  without increasing competence.
- The learner MUST finish with a new practical ability, not only additional
  isolated facts.

# 12. Internal Audit Requirements

- This standard MUST reject a 20-screen lesson built around one greeting when
  the screens do not each prove a distinct necessary learner-state transition.
- This standard MUST reject excessive repetition when repeated activity does not
  improve stability, transfer, confidence or evidence quality.
- This standard MUST reject insufficient communication when a communicative
  objective ends with exposure, copying or recognition only.
- This standard MUST reject isolated vocabulary memorization when vocabulary is
  not immediately used for the lesson objective.
- This standard MUST reject unnecessary phonetic theory when it does not help
  the next learner action.
- This standard MUST reject empty filler screens when removing them would not
  weaken learning, assessment, correction or communication.
- This standard MUST reject a lesson that an adult would reasonably abandon
  after a full working day because the learning gain is unclear, repetitive or
  inefficient.

# 13. Adult Learner Experience Rules

- Tutor Language MUST assume that adult learners prefer understanding over
  blind repetition.
- Tutor Language MUST respect adult intelligence.
- Tutor Language MUST NOT use artificial simplification that removes meaningful
  learner thinking.
- Tutor Language MUST NOT use childish tone, childish scenarios or childish
  rewards.
- Beginner lessons SHOULD use simple language without treating the learner as a
  child.
- Every lesson SHOULD allow the learner to perform a realistic action that could
  plausibly occur outside the application.
- Every lesson MUST make the newly acquired ability visible by the end.
- The learner MUST be able to identify what they can now do that they could not
  do before the lesson.
- Adults MUST NOT repeat an activity unless the repetition provides a different
  learning benefit.
- Repetition for adults MUST strengthen recall, transfer, confidence, accuracy,
  speed, correction or independent use.
- Every learner action SHOULD maximize learning gained per minute invested.
- Lessons MUST NOT include interactions that consume time without increasing
  competence.
- Examples SHOULD resemble situations adults actually encounter.
- Examples SHOULD NOT use unrealistic textbook exchanges when a plausible adult
  situation can serve the same objective.
- Lessons SHOULD occasionally require simple reasoning, comparison, prediction
  or inference.
- Lessons MUST NOT rely primarily on passive memorization when an active
  learner decision can teach the same point.
- The application MUST gradually reduce support.
- The learner SHOULD solve communicative tasks with increasing independence.
- Motivation MUST arise primarily from growing competence.
- Artificial praise MUST NOT substitute for measurable progress.
- Lessons SHOULD create curiosity, confidence and satisfaction from successful
  communication.
- Lessons MUST NOT create frustration through unnecessary difficulty,
  unsupported recall or hidden prerequisites.
- Interaction cost MUST remain low.
- Reading load MUST remain appropriate for a 6-7 inch smartphone.
- Every screen SHOULD feel worth opening.
- Adult-facing lessons SHOULD avoid decorative screens unless the screen
  performs a necessary learning, correction or transition function.
- Adult-facing lessons MUST NOT use gamification as a substitute for meaningful
  learning progress.
- Adult-facing lessons MAY use light interaction variety when it reduces fatigue
  without distracting from the lesson objective.

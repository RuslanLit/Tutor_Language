# First public release screenshot checklist

Capture these screens from the current release-equivalent executable and UI
after the public-facing copy and final visual QA are complete. A DEBUG/QA build
may be used solely as a navigation aid if the screenshots use current release
source and content, no DEBUG ribbon or QA/developer controls are visible, no
internal IDs or test fixtures appear, learner-facing rendering matches the
release UI, and the actual release build has separately passed build and
QA-exclusion checks.

Capture the complete set in each release educational support locale:

- Ukrainian;
- Russian;
- English.

1. **Course path** — the course overview showing the completed Spanish A0
   path and the beginning of the A1 routine module (Lessons 38–42).
2. **Sentence construction** — the sentence-builder step in Lesson 30,
   “Короткий опис сім’ї та дому”, showing learner-facing tokens and feedback.
3. **True listening comprehension** — the audio-first listening step in Lesson
   35, “Лікар, аптека і допомога”, or the listening checkpoint in Lesson 42.
4. **Guided dialogue** — the guided exchange in Lesson 21, “Попросити про
   допомогу”, showing the visible interlocutor context and learner turn.
5. **Typed production or checkpoint** — typed recall in Lesson 30 or the final
   A0 checkpoint in Lesson 37, showing ordinary learner-facing completion.

Before capture, verify that each screen:

- represents the current release UI and contains no debug/QA-only visual state;
- contains no QA or developer controls;
- does not expose internal asset IDs;
- shows readable learner-support text in the applicable release locale and
  Spanish target content;
- does not imply that the A1 course is complete or that speech is scored
  automatically.
